## 一、Windows 安装 Docker Desktop（2026 最新版）
### 1. 系统与硬件要求（必须满足）
- **系统**：
  - Windows 10 64位：22H2+（Build 19045+）
  - Windows 11 64位：任意版本
- **硬件**：
  - CPU 支持 **Intel VT-x / AMD-V 虚拟化**（BIOS 必须开启）
  - 内存 ≥ **4GB**（推荐 8GB+）
  - 硬盘：SSD，C盘 ≥ 20GB 可用空间
- **检查虚拟化**：
  任务管理器 → 性能 → CPU → 右下角：**虚拟化：已启用**


### 2. 启用 WSL 2（必做，推荐后端）
以**管理员**打开 PowerShell，执行：
```powershell
wsl --install
```
- 自动安装：WSL 2 内核 + Ubuntu（默认Linux）
- 安装完成后 **重启电脑**

### 3. 下载 & 安装 Docker Desktop
1. 官网下载（2026.5 最新）：
   https://www.docker.com/products/docker-desktop/
   - 选 **Download for Windows (x86_64)**（绝大多数PC）


2. 运行 `Docker Desktop Installer.exe`
   - 勾选：**Use WSL 2 instead of Hyper-V**（必选，性能更好）
   - 勾选：**Add shortcut to desktop**（方便启动）


3. 点 **OK → 等待安装 → 重启电脑**

### 4. 首次启动 & 验证
1. 双击桌面 Docker 图标启动
2. 接受协议，**注册/登录 Docker Hub**（免费）
3. 任务栏出现 **小鲸鱼 🐳** 即成功


4. 打开 PowerShell 验证：
```powershell
docker --version   # 查看版本
docker run hello-world   # 跑测试容器
```
出现欢迎信息 = 安装成功！


### 5. 常见问题
- **虚拟化未开启**：重启 → 进 BIOS → 开启 Intel VT-x / AMD-V
- **WSL 安装失败**：
  ```powershell
  wsl --set-default-version 2
  ```
- **企业用户**：需把当前用户加入 `docker-users` 组
  ```powershell
  net localgroup docker-users %username% /add
  ```

## 二、Docker 相关的道德、伦理与合规问题（程序员必知）
### 1. **Docker Desktop 授权与付费道德（2026 政策）**
- **免费适用**：
  - 个人使用、学习、开源贡献
  - **≤250人公司 且 年收入＜$1000万**
- **必须付费**（企业订阅）：
  - **＞250人 或 年收入≥$1000万** 的商业公司
- **道德争议点**：
  - Docker 从“完全免费”转为**商业收费**，被部分开发者视为**背叛开源精神**
  - 强制登录、限制免费功能，引发社区不满
- **你的道德选择**：
  - ✅ **合规**：公司规模达标 → 买订阅（法律+道德责任）
  - ✅ **个人/学生**：免费使用完全合法

### 2. **容器镜像的安全伦理**
- **公共镜像风险**：
  - Docker Hub 上**数万镜像含密钥、密码、API密钥**（2025研究）
  - 用恶意镜像 = 主动引狼入室（数据泄露、挖矿、入侵）
- **道德责任**：
  - ✅ 只拉 **官方镜像（official）**、**可信机构**镜像
  - ✅ 自己构建镜像：**清除密钥、证书、敏感配置**
  - ✅ 不传播含后门/恶意代码的镜像（违法+不道德）

### 3. **开源合规与版权道德**
- Docker 核心是开源，但 **Docker Desktop 是商业产品**
- 容器内软件同样受版权：
  - 不能用 Docker 封装**盗版软件**商用
  - 遵守容器内所有软件的 **开源协议（GPL/MIT/Apache）**
- **道德底线**：
  - 不盗用他人镜像、不破解付费功能、尊重开发者劳动

### 4. **资源滥用与职场伦理**
- 公司环境：
  - ❌ 不私自用 Docker **跑挖矿、挂游戏、占用大量资源**
  - ❌ 不用容器**逃避公司安全监控、违规翻墙**
  - ✅ 仅用于**开发、测试、工作**，遵守公司IT政策

### 5. **技术中立与社会责任**
- Docker 是工具，**善恶在使用者**：
  - 可用于**金融、医疗、公益**（正面）
  - 可用于**网络攻击、诈骗、恶意爬虫**（负面）
- **程序员道德准则**：
  - 技术服务于**合法、合规、向善**的目的
  - 拒绝参与**危害安全、侵犯隐私、违法牟利**的项目
