


## Hermes 介绍

## Hermes 支持的厂商


Hermes 原生支持国内主流的大模型平台，对于国内用户而言，配置 API 非常便捷，无需特殊网络环境。关于“免费”的国内 API，目前主要有以下几种获取免费额度或低成本试用的方案：

推荐方案：Kimi（Moonshot）
Kimi 是国内用户部署 Hermes Agent 的优选方案，具备出色的中文语义理解能力和长上下文处理能力。
免费额度：新用户注册后通常可获得对应免费额度，轻量使用成本极低。
配置方式：登录 Kimi 开放平台控制台（platform.moonshot.cn），在「API Key 管理」页面新建密钥即可。

NVIDIA NIM API
NVIDIA 提供了国内直连的 API 服务，无需代理即可顺畅访问。
免费额度：注册账号并完成手机号验证后，创建 API Key 即可使用其赠送的免费额度。
配置方式：在 build.nvidia.com 注册并创建 API Key，在 Hermes 中选择 NVIDIA NIM 作为提供商。

DeepSeek API
DeepSeek 是国内非常优秀的备选模型，计费相对良心。
免费/低成本：通常提供一定的免费额度，且充值少量金额即可使用很久。
配置方式：前往 DeepSeek 官网（platform.deepseek.com）注册认证并创建 API Key。

讯飞星辰 MaaS
免费额度：提供免费的模型调用额度，是一个一站式的 AI 大模型体验与调用平台。

阿里云 DashScope（通义千问）
免费额度：阿里云 DashScope 平台通常会为新用户提供一定额度的免费 Token。
配置方式：在阿里云 DashScope 控制台获取 API Key，并正确配置国内版 Base URL。

💡 核心提示：
国内大模型的“免费”通常指的是新用户注册赠送的免费额度或限时免费体验。建议你在注册上述平台后，优先使用 Kimi 或 NVIDIA NIM 的免费额度进行 Hermes 的初始测试；待免费额度消耗完毕后，再根据实际使用量选择性价比最高的平台进行小额充值。
