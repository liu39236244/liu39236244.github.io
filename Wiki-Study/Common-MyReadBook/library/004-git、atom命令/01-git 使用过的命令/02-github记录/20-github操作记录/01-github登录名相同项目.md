### 如何查看ip

你的仓库名是 test123.github.io

你本机ping test123.github.io 就能知道ip

最早期返回的是ipv4的地址

### 买域名以后解析

域名  yabobj.cn 为例，想要用二级域名 yun.yabobj.cn

#### 解析方式1 

主机记录：
yun
记录类型：
AAAA

线路选默认
记录值：就是把自己的IP放进去

#### 解析方式2

主机记录：
yunn
记录类型：
CNAME
线路默认
记录值：
liu39236244.github.io
